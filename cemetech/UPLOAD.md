# Cemetech submission kit

1. Sign in at <https://www.cemetech.net/downloads/upload>.
2. Choose the matching **TI-84 Plus CE native C/assembly games** category offered by the current form.
3. Upload **`DriftBossCE-v0.2-Cemetech.zip`** as the program archive.
4. Use **Drift Boss CE v0.2** as the title and **Lord-Funion** as author. Paste `description.txt`, or the BBCode version if the form supports it.
5. For the listing’s four screenshot slots, choose the GIF files in `Screenshots/Cemetech/`: `01-gameplay.gif`, `02-later-run.gif`, `03-garage.gif`, and `04-boosters.gif`.
6. Check the current form’s limits and submit. Cemetech reviews uploaded programs; this package does not guarantee approval.

The four suggested GIFs total 336,814 bytes; the program ZIP is kept below 2 MB. This conservative sizing follows the archive’s [published upload guidance](https://www.cemetech.net/forum/viewtopic.php?t=4531) and [screenshot guidance](https://www.cemetech.net/forum/viewtopic.php?t=13480), which may differ from the current login-only form. Full-size PNGs are included alongside the compact GIFs.

The package includes runtime files, source, installation instructions, component notices, original-game credits, and truthful capture captions. It is prepared for you to upload; it has not been submitted to Cemetech automatically.
