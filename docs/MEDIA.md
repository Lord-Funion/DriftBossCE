# Screenshots and GIFs

All gameplay pictures come from **Drift Boss CE v0.2’s compiled eZ80 game core and renderer**, running with the real graphx library in a CPU-only CEmu-core harness. No screenshots are AI-generated. No calculator ROM is included. They are synthetic native-renderer captures, not photographs or full-OS emulator recordings.

The deterministic capture contains 435 completed native frames: eight garage previews, booster/help screens, a scripted 1,694-tick driving run, and game over. A native/host replay comparison checks the 19 final gameplay values. The driver fixture is not part of the calculator release.

- `gameplay.gif` and `later-run.gif`: full 320×240 exports, 8 seconds each, sampled at 10 FPS.
- `garage.gif`: all eight garage previews.
- `*.png`: unretouched 320×240 framebuffer captures.
- `screenshots.png`: a labeled contact sheet of the native captures.
- `banner.svg`: a typography/design panel for this repository, not a gameplay screenshot.

The suggested Cemetech screenshot set has two smaller 160×120, 4-second gameplay GIFs, a 320×240 garage GIF, and a 320×240 booster still GIF. Their combined size is **336,814 bytes**. Full-size PNGs are also included in the release ZIP. Select the four GIFs as the listing screenshots if the current upload form permits them.

The GIF frame rate is an export choice and does not measure calculator performance. The owner reported approximately 22 FPS on their calculator. Color indices are preserved from the native palette; downscaling for the compact GIFs uses nearest-neighbor sampling.
