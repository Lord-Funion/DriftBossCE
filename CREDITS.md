# Credits and provenance

- **MarketJS:** original Drift Boss game, name, models, textures, vehicle/platform/UI artwork, and reference gameplay design.
- **Math Playground:** browser version used as the port’s reference: <https://www.mathplayground.com/pg_drift_boss.html> and <https://www.mathplayground.com/drift-boss-v3/index.html>.
- **Lord-Funion:** native calculator adaptation, testing feedback, and release maintenance, with development assistance from Codex.
- **CE Programming:** CE C/C++ Toolchain v15.0 and the `graphx`, `fileioc`, `keypadc`, and `libload` runtimes. <https://ce-programming.github.io/toolchain/> and <https://github.com/CE-Programming/libraries>.
- **CEmu contributors:** CPU/emulator core used for native regression tests and media capture. <https://github.com/CE-Programming/CEmu>.

The game’s native engine is a replacement for the original Babylon.js/WebGL/Cannon runtime. Original browser JavaScript, ad code, TI ROMs, and toolchain executables are not part of this repository. Generated binary asset banks are included to make the native project buildable.
